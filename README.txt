NEON TRAIL — UPGRADED ENDLESS RUNNER
===================================

Files:
- index.html
- main.css
- main.js
- road.png
- runner.png

Run:
1. Keep all five files in the same folder.
2. Open index.html in a modern browser, or use VS Code Live Server.
3. On desktop: Arrow keys / WASD to move and jump, P or Esc to pause.
4. On mobile: swipe left/right/up, or use the on-screen buttons.

The original cat sprite and road image are preserved. Core 3-lane movement,
jumping, coins, bombs, score and level progression remain in place.

Note: Google Fonts needs an internet connection; system fonts are used as fallback.
